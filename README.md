A modern, high-performance, responsive personal portfolio website for **Tejendra Singh**, Data Science Professional, Machine Learning & Artificial Intelligence Specialist.

This repository is built strictly using **Pure HTML5** and **CSS3** — **No JavaScript**, **No Bootstrap**, and **No external frameworks** were used.

---

## 🛠️ Stacks & Concepts Used

The project strictly demonstrates mastery of raw web technologies and core concepts:

- **HTML5**: Semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, `<table>`, `<form>`, etc.)
- **CSS3**: Custom CSS variables, glassmorphism UI, gradient accents, styling reset.
- **Semantic HTML Tags**: Clean document structure, accessible headers, proper heading hierarchy (`<h1>` to `<h3>`).
- **Navigation & Hyperlinks**: Sticky navigation header with smooth anchor scrolling (`#about`, `#experience`, `#projects`, `#education`, `#skills`, `#certifications`, `#contact`), external links with security attributes (`target="_blank" rel="noopener"`).
- **Images**: Profile picture integration, optimized responsive sizing, backdrop glow framing.
- **Lists**: Unordered lists (`<ul>`) with custom CSS pseudo-element bullets (`::before`) for career achievements and summary highlights.
- **Tables**: Standard HTML `<table>` elements with custom table styling, hover effects, and responsive overflow wrappers to showcase academic degrees.
- **Forms**: Interactive HTML5 contact form using `<input>`, `<select>`, `<textarea>`, floating field focus glows, and form submit handlers.
- **CSS Flexbox**: Header alignment, navigation menu layout, timeline cards, project tags, and footer layout.
- **CSS Grid**: Multi-column project grid, skills matrix breakdown, certifications catalog, and hero/contact split layouts.
- **Hover Effects**: 3D card transforms (`translateY`), glow borders, gradient shifts, link hover underlines, and button focus states.
- **CSS Transitions & Animations**: `@keyframes` ambient backdrop glowing pulse, live status dot animations, smooth state transitions.
- **Media Queries & Responsive Web Design**: Breakpoint optimizations (`@media (max-width: 992px)`, `@media (max-width: 768px)`, `@media (max-width: 480px)`).
- **Pure CSS Mobile Navigation Toggle**: Mobile hamburger menu powered via pure CSS input checkbox hack (`:checked ~ .nav-links`).
- **GitHub Repository Ready**: Modular folder structure (`index.html`, `css/style.css`, `assets/images/`).
- **GitHub Pages Ready**: Optimized static assets for instant hosting.
- **README.md**: Full project documentation and deployment instructions.
- **MIT License**: Open-source license included.

## 🌐 Deploying to GitHub Pages (Step-by-Step)

Follow these easy steps to deploy your portfolio live on GitHub Pages:

### Step 1: Create a New GitHub Repository
1. Go to [GitHub](https://github.com/new).
2. Name your repository: `portfolio` or `tejendra-portfolio` (or `<your-username>.github.io`).
3. Keep it **Public**.
4. Do **not** initialize with a README (as we already have a customized `README.md`).
5. Click **Create repository**.

### Step 2: Push Local Files to GitHub
Open your terminal inside the project root folder (`Portfolio 1`) and run:

```bash
git init
git add .
git commit -m "Initial commit: Pure HTML5 & CSS3 Data Science & AI Portfolio"
git branch -M main
git remote add origin https://github.com/tejendra9068/Portfolio.git
git push -u origin main
```

*(Replace `tejendra9068/Portfolio.git` with your actual repository URL)*

### Step 3: Enable GitHub Pages
1. On GitHub, navigate to your repository **Settings** tab.
2. Scroll down on the left sidebar to **Pages** (under the "Code and automation" section).
3. Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
4. Under **Branch**, select `main` branch and `/ (root)` folder.
5. Click **Save**.

### Step 4: Access Your Live Website
- Wait 1-2 minutes for GitHub Actions to complete the deployment.
- Your website will be live at:
  ```
  https://tejendra9068.github.io/Portfolio/
  ```
